# Appendix B — Weapons and armour (4e core vs 5e core)

> Generated from the 5e Consumer Guide tables (pp. 301–307) and the 4e core items in the production DB dump. Changed values are **bold** with the 4e value in brackets. 4e prices are converted from pennies. This covers only the weapon and armour tables; other trappings (containers, clothing, tools, animals, herbs, poisons, prosthetics, magic items, hirelings) have not been compared yet — see the tracker.

Note: the 5e ranged table states that all Blackpowder, Engineering and Explosive weapons have the Blackpowder and Damaging Qualities; they are added to the 5e column below so they do not show up as differences.
