## Quality versions (D4)

Decided per base trapping (D4a): weapons and Helm in four versions (Durable 1, Fine 1, Lightweight, Practical); clothing-like trappings and Symbol of Rank in a Fine 1 version; Trade Tools - Engineer Practical; Blanket Ugly. "Quality X" in a career is a choice between the versions when there are several. Price and Availability (p. 298): each Quality doubles the price and makes it one step rarer, each Flaw halves it and makes it one step commoner; Fine 2 is one Quality (× 2, 2026-10-22). Lightweight is −1 Enc. The other values (damage, AP, qualities) are copied from the base trapping.
