## Quality versions (D4)

Decided per base trapping (D4a): weapons and Helm in four versions (Durable 1, Fine 1, Lightweight, Practical); clothing-like trappings and Symbol of Rank in a Fine 1 version; Trade Tools - Engineer Practical; Blanket Ugly. "Quality X" in a career is a choice between the versions when there are several. Price: each Quality doubles it, each Flaw halves it (p. 298); Lightweight is −1 Enc. The other values (damage, AP, qualities) are copied from the base trapping.
