# HG-40 Career trappings as a list

Tracking folder for HG-40 (`docs/issues/functional.md`). Delete the folder when HG-40 is done.

Goal: each career level gets a list of trappings (ids with quantities, choices and dice) instead of free text. The list is edited with a picker, shown on the career page and added by the generator.

Data and scripts are in `db/data/hg-40/`. That folder is gitignored and exists only on the owner's machine: it is the only copy of the mapping (`alias.py`) and of the scripts, so keep it backed up. Run from that folder, in this order:
1. `python3 dump.py` (needs pymongo: `../../../.venv/bin/python`): reads the public careers and trappings from local `hammergenGo` into `careers.json` and `items.json`. Only needed when the database changed.
2. `python3 parse.py`, `python3 norm.py`: split the text into entries (`entries.json`) and atoms (`atoms.json`).
3. `python3 final.py`: maps every atom with `match.py` (name matching), `alias.py` (hand-made mapping) and `cat.py` (categories) into `career-trappings-resolved.json`, the input of the migration script.
4. `../../../.venv/bin/python gen_docs.py` (reads trapping prices from local `hammergenGo`): regenerates `new-trappings.md` and `aliases-5e.md`, and writes the mapping per career to `db/data/hg-40/careers-5e.generated.md` (gitignored). It never writes `docs/hg-40/careers-5e.md`, which the owner edits by hand: mapping changes are carried over to it by hand, using the generated file to compare. It keeps the hand-kept Price, Enc and Status in `new-trappings.md`; anything else edited by hand in the generated files is overwritten.

Rerunning steps 2–4 without changes gives identical files (checked 2026-10-19).

How `alias.py` works: `A` maps book text (lower case) to targets for all careers (`I:` existing trapping, `N:` new trapping, `C:` category or note, `|q` quality); `CHOICES` maps (career, level, book text) to options for one 5e career level and wins over `A` (`#n` quantity or dice, `T:` note on the previous trapping, `C:NOTE=text` a level note); `VERSIONS` lists the quality versions; `BOOK_NAME_NOTE` the book names kept as trapping notes (D14); `SPLIT` splits one book entry into several. The file is appended to over time, so a later assignment overrides an earlier one. Corrections from the review go into `alias.py`, then rerun steps 3 and 4.

## Decided

- No "group" trappings: choices ("A or B") and dice ("1d10") are stored in the list itself.
- Converted public careers lose the free text. New careers have no free-text field. The field is shown only for levels that still have text.
- New 5e trappings are created as 5e-only documents; the 4e variant is added later when the 4e careers are converted (1-to-1 links).
- D1 Format: [analysis.md](analysis.md#format). A level has `trappings` (entries → options → trappings with quantities and an optional `value`, the note on the trapping), `money` (coins with fixed or dice amounts) and the old `items` text (no `notes`: D20). An entry with several options is a choice: the generator picks one at random, guided creation (career level 1 only) lets the player pick. All 5e book entries are choices. (A `selection` of `choice` or `random` was dropped on 2026-10-22: no data needs random; add it back if guided creation or 4e data needs it.)
- D2 Non-trappings: places, vehicles and animals become trappings of type Other, "Cannot be carried", like the existing Riding Horse, Cart and `Workshop - <trade>` (e.g. Townhouse, Temple, Warehouse, Sailing Ship, Kennel). People, intangibles and lands became short notes per level at first; since D20 they are generic trappings too. Mixed entries become the trapping with a note on it: "Townhouse with Servants" → Townhouse ("with Servants").
- D3 Money: kept on the career level as coins (gold crowns, shillings, pennies), each a fixed number or dice ("3d10"); the career page shows it and the generator rolls it and adds it to the character's coins. 5e: Trader 3d10/–, Merchant 20 GC, Master Merchant 100 GC, Merchant Prince 1000 GC, Grandee 200 GC, Noble Lord 500 GC, Wandering Trader 4d10/–.
- D3a "Worth" entries are trappings: "Jewellery worth 50 GC" → the existing Jewellery (price 0, its value varies), "Goods worth 2d10 Pennies" (Pedlar 1–4) → new Trade Goods, "Stolen Goods worth 1d10 Shillings" (Fence 1) → Trade Goods too (the note says they are stolen). The stated worth is a note on the trapping ("worth 50 GC", "stolen, worth 1d10 Shillings"); it is not added to the coins.
- D4 Quality: "Quality X" and "Poor Quality X" become separate trappings with the qualities or flaws set, e.g. "Clothing (Fine)" with Fine 1. A character stores only a trapping id and a count, so the quality must be part of the trapping. 15 base trappings, 32 uses in 5e.
- D4a Quality versions: weapons and Helm in four versions (Durable 1, Fine 1, Lightweight, Practical); trappings not used in Tests (clothing, Cloak, Hat, Robes, Uniform, Courtly Garb, Symbol of Rank) in a Fine 1 version (Fine 2 for Envoy 4's "Best Quality Courtly Clothes"); Trade Tools - Engineer (Practical); Blanket (Ugly) and Jewellery (Ugly, Mystic 1 "Cheap Jewellery"). Servant 4 "Fine Clothes" is Clothing (Fine), not the existing Fine Clothing. Judicial Champion's "2 Quality Weapons" is a choice of the Sword, Rapier, Foil, Pistol and Handgun versions (the guns with 10 Bullet and Powder); Pistol has no Lightweight version (Enc 0). "Quality X" with several versions is a choice between them. Lightweight only where it lowers Enc: equipped weapons count their full Enc, so Lightweight helps from Enc 1 (1 → 0); worn armour and clothing already count 1 less, so it helps only from Enc 2 (Helm 2 → 1). Price and Availability (book, Item Qualities): each Quality doubles the price and makes the trapping one step rarer, each Flaw halves the price and makes it one step commoner (Availability added 2026-10-22); Fine 2 counts as one Quality (× 2, not × 4; 2026-10-22). The Duellist's quality weapons (Duelmaster's "Quality Rapier", Judicial Champion's "2 Quality Weapons") are only the Fine versions, as are Watch Captain's "Quality Hand Weapon" and Pit Legend's "Quality Helmet" (2026-10-22, `QUALITY_ONLY` in `alias.py`; the Ugly, Practical and Fine 2 versions are single versions, not choices); the other versions stay trappings, listed as used by no career. Each of the Herb Master's three remedies is a choice of a third of the 11 5e remedies (Blight to Coughs and Sneezes, Fever to Infection, Malaise to Pox; 2026-10-22, `ENTRY_OPTIONS` in `alias.py`). A note has no brackets of its own, as it is shown in brackets after the trapping: "Library (Law)" is Holding ("Library - Law") (2026-10-23, `final.py`); the Lawyer's "Assistant (Student or Servant)" is a choice of Retainer ("Student") or Retainer ("Servant"). Watch Captain's "Quality Hand Weapon" is Hand Weapon (Fine) (since 2026-10-22; it was a choice of the four versions). 39 versions.
- D5 Generic weapons: an explicit choice list per career level (in `CHOICES`, `db/data/hg-40/alias.py`); the same is used for "Instrument" (Small/Medium/Large) and "Poison" (Hitman). Ranged options come with 10 ammunition, as the other careers' entries do ("Bow with 10 Arrows").
- D6 Grimoire: a generic Grimoire trapping (type Grimoire, no spells).
- D7 Libraries and workshops: the missing ones become non-carriable trappings (Library - Art/Engineering/Law/Theology, Workshop - Artist/Engineer - Large). "Trade Tools (as Trade)" and "Workshop (as Trade)" map to the existing Trade Tools - Artisan and Workshop - Artisan.
- D8 Generator: a character of level N gets the trappings (and money) of levels 1 to N. The book gives level 1 trappings at creation and expects the higher levels' trappings to be acquired while advancing; lacking them lowers Status ("Maintaining Status"). Trappings from the next level tick the Career Advancement Tracker (sheet, p. 191, p. 196): the 5e generator (`advancement5e.ts`) counts the trappings of level n+1 as ticks of the segment before level n+1, so fewer career skill Advances (and less XP) are needed. Checked: talent + characteristic Advances + next-level entries never exceed a segment (Grave Robber 1→2 and Witch Hunter 1→2 fill it exactly).
- D9 Aliases: [aliases-5e.md](aliases-5e.md) and the D5 choice lists confirmed 2026-10-18, with these changes: Seal of Office → Stamp - Engraved; new Magic Licence and Book (Scholar 1); Plumed Great Helm → Helm; Pots and Pans → Cooking Pot + Pan; Wardrobe of Costumes → 5 × Costume; Selection of Amulets → 1d6 × Amulet; 3 Herbal Remedies → three separate choices of the 11 5e Remedies (three entries, so three tracker ticks); Sack of Poisoned Bait → Sack + Rat Poison; Destrier without a saddle; Ceremonial Cloak → Cloak (Fine); Hiding Place → note; Alcohol → Flask of Spirits; Plate Armour → Breastplate, Bracers, Plate Leggings, Helm; Guild and fleets as notes. Later corrections from the career review (step 2) are in `alias.py` and show in [careers-5e.md](careers-5e.md).
- D10 Tracker ticks: one tick per book entry of the next level: a single trapping, a bundle ("Bow with 10 Arrows"), a choice and money ("20 GC"), including the generic trappings of D20 ("Squire" → Retainer (Squire)); a level's tick count is entries + money items. A note on a trapping ("Coach and Footman" → Coach ("with a Footman")) is part of its entry and doesn't tick separately.
- D11 Fine Clothing: the 5e Courtier class trapping in `generationProps5e` becomes Clothing (Fine), and the 5e variant of Fine Clothing (`5f1cb495f3230369ab4eb3d3`, no qualities, 1 GC) is removed. The document keeps its 4e variant, which 4e careers use. No character has it today (local snapshot, 2026-10-18); check again in each environment before removing.
- D12 Troll Slayer (Slayer 1) "Hand Weapon (Dwarf Axe)" → Hand Weapon with the note "Dwarf Axe" (D16); Giant and Dragon Slayer's Greataxe and Throwing Axe without a note.
- D13 Notes on the character: a note on a trapping becomes the value of that trapping on the character (D17), e.g. "Coach (with a Footman)", "Legal Document (Letter of Appointment)". The generator writes nothing into the character's free-text notes (changed by D20: there are no stand-alone notes any more).
- D14 Book names as trapping notes: when the book's name says what the thing is and the trapping it maps to doesn't, the book's name becomes the trapping's note: Legal Document ("Letter of Appointment", "Orders", "Degree"), Symbol of Rank ("Rod of Office"), Courtly Garb (Servant) ("Livery"), Telescope ("Spyglass"), Hat ("Mortarboard"). Adjectives, purposes, synonyms and pure wording differences get no note ("Sturdy Boots", "Pole for Dead Rats", "Shovel", "Rope"). The list is `BOOK_NAME_NOTE` in `db/data/hg-40/alias.py`. On the character the note is the trapping's value (D17).
- D15 Tattoo: the 5e Tattoo (`6ac4ae0780c7a9f35b5112ea`, 5e only, used by Troll Slayer 1) changes from "Can be carried and worn" to "Cannot be carried" (carry type 2), so it never counts towards Encumbrance.
- D16 Hand Weapon variants (changed 2026-10-20): axes, picks and boat hooks used as hand weapons are the Hand Weapon trapping with a note (D17): "Axe" (Trapper, Villager 2, the "Hand Weapon / Hand Weapon (Axe)" choice of every plain Hand Weapon entry, the choices of Fencer, Knight 2, Neophyte, Warrior Priest 2, Soldier 2, and the Hand Weapon quality versions for Watch Captain), "Dwarf Axe" (Troll Slayer), "Pick" (Prospector), "Boat Hook" (Boathand, Riverguide, Sailor 2, Dockhand, Wrecker 2). No 5e Axe variant, no Hand Pick, no Boat Hook (Weapon), no Axe quality versions. The 5e Boat Hook and Pick (Tool) stay tools (Tomb Robber gets Pick (Tool)).
- D17 Trapping values on the character (2026-10-20, deployed 2026-10-21; was the backlog issue HG-49): a character's trappings store a value next to the id and number, as traits do (`IdValue`): `{id, number, value}`, shown as "Hand Weapon (Axe)". The same trapping can be listed more than once with different values (a Hand Weapon and a Hand Weapon (Axe)). The generator puts a career trapping's note into that value. Open details: see "Open decisions".
- D18 Length of a trapping value: 40 characters (traits keep 20); the longest career note has 30.
- D19 Character trappings model ([plan-trapping-values.md](plan-trapping-values.md), agreed 2026-10-20): `{id, number, value}` entries; the career format names a trapping's note `value` too; the character values are done first as their own change (step 2a), then the career trappings (steps 3–7); rows are not merged: each Add in the popup is a row of its own (changed 2026-10-20).
- D20 No notes (2026-10-21): every book entry becomes a trapping. The stand-alone notes of D2 are seven generic trappings (type Other, "Cannot be carried", no price or Enc) with the book's text as their value; countable people use the quantity:
  - Retainer: people who serve the character, e.g. Retainer (Apprentice), Retainer (Squire), 4 × Retainer (Household Servant), 3 × Retainer (Pamphleteer).
  - Contact: Contact (Fence), Contact (Several Fences), Contact (Patron).
  - Command: groups and things the character leads or manages, e.g. Command (Squad of Guards), Command (Regiment of Soldiers), Command (Patrol Boats and Crew), Command (Guild).
  - Animal Companion: Animal Companion (Trained Animal).
  - Holding: Holding (Fiefdom), Holding (Province), Holding (Hiding Place), Holding (Access to a Library).
  - Reputation: Reputation (Respected by the Village).
  - Magic Item: Magic Item (chosen with the GM), Magic Item (Rune Axe) (HG-52; HG-53 closed, 2026-10-23).
  The list is `GENERIC` in `db/data/hg-40/alias.py`.
- D21 Places (2026-10-21): a place the character manages for someone else is Command, e.g. Command (Temple) for a High Priest, Command (Abbey), Command (Governor's Residence), Command (Office and Staff), Command (Hawk Mews) / Command (Kennel of Hunting Dogs). A place the character owns or has access to is its own trapping when the 5e rulebook lists it as one (only Workshop: one Workshop and a new Large Workshop at double the cost, 160 GC, with the trade as value, e.g. Workshop (Apothecary), Large Workshop (Artist), Workshop (own trade) for "as Trade"); every other place is Holding with the book's name, e.g. Holding (Townhouse with Servants), 2 × Holding (Warehouse), Holding (Library (Law)), Holding (Lodgings), Holding (Remote Lair), Holding (Lair) for the Beggar King, Bandit King and Gang Boss (2026-10-22: a gang's lair belongs to its leader; the gang itself is Command). Vehicles with crew follow the same rule (2026-10-22): a vehicle the 5e rulebook lists keeps its trapping with the crew as value (River Barge ("with Crew") for the Barge Master, River Barge ("with Wrecker Crew") for the Wrecker Captain); one it does not list is Command (Command (Sailing Ship and Crew) for the Ship's Master, like Command (Patrol Boats and Crew)). A vehicle without crew that the book doesn't list is a new trapping of its own (Riverboat for Pilot 4's "Small Riverboat", Handcart for Grave Robber 1; 2026-10-23), not a Holding, which is for places. Lists: `PLACE_TRAPPINGS`, `MANAGED_PLACES` in `db/data/hg-40/alias.py`. Trade Tools work the same way: one Trade Tools trapping with the trade as value (Trade Tools (Carpenter), Trade Tools (own trade) for "as Trade"; the Chartered Engineer's quality version is Trade Tools (Practical) with "Engineer"). The existing 5e "Workshop - …", "Trade Tools - …" and "Library - Magic" trappings are no longer used by careers; they are removed later, together with other similar trappings.
- D22 4e content in careers (2026-10-22): 5e careers use 5e content only; their editor offers only 5e trappings, skills and talents (a user who needs 4e-only content makes a 5e version of it). 5e characters reach 4e-only careers through "Allow 4e content" as before; how those careers' skills, talents and trappings work for 5e characters (lookups by shared document, a "5e equivalent" link, 5e versions of popular 4e careers, generating from 4e careers) is left for the 4e part of HG-40.
